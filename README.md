# Simple-interest-calculator
This is a responsive and user-friendly web-based Simple Interest Calculator built using HTML for structure, CSS for custom styling, and Bootstrap for layout and responsiveness. It allows users to quickly calculate the simple interest on a principal amount over a certain time period at a given rate of interest.

✅ Features:

1] Input Fields:

   1.1) Principal Amount (in currency)
   
   1.2) Rate of Interest (annual %)
   
   1.3) Time Period (in years)

2] Output:

   2.1) Automatically displays the calculated Simple Interest

   2.2) Shows the Total Amount (Principal + Interest)

3] Responsive Design: Layout adjusts seamlessly on desktops, tablets, and mobile devices using Bootstrap's grid system.

4] Interactive UI:

   4.1) A clean, professional look with Bootstrap components like cards, forms, and buttons.

   4.2) Instant feedback when the "Calculate" button is clicked.


🛠️ Technologies Used:

1] HTML5: Defines the structure of the calculator form.

2] CSS3: Adds basic custom styling and design improvements.

3] Bootstrap 5: Ensures responsive design and enhances layout with predefined classes.
